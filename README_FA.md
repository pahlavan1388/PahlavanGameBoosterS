# Pahlavan Game Booster X — نسخهٔ آزمایشی 0.1

این فایل **پروژهٔ سورس اندروید** است، نه APK آماده. در این محیط Android SDK/Gradle نصب نیست؛ بنابراین APK کامپایل یا روی Galaxy M12 آزمایش نشده است.

## امکانات موجود در سورس
- داشبورد فارسی
- آزمون زمان اتصال TCP به چند مقصد، با میانگین و نوسان تقریبی و شمارش تلاش‌های ناموفق
- نمایش RAM آزاد/کل، حافظهٔ مصرفی خود برنامه و دمای باتری
- دکمهٔ شناور قابل‌جابجایی با مجوز نمایش روی برنامه‌های دیگر
- ذخیرهٔ پروفایل‌های سرور و واردکردن آرایه JSON از فایل

## محدودیت مهم
**VPN واقعی هنوز پیاده‌سازی نشده است.** این نسخه تونل نمی‌سازد و پروفایل‌ها صرفاً ذخیره می‌شوند. برای VPN عملی باید یک موتور معتبر مثل WireGuard Android یا OpenVPN به پروژه اضافه و با پیکربندی و مجوزهای مربوطه یکپارچه شود. هیچ سرور VPN رایگانی در برنامه تعبیه نشده است. آزمون شبکه هم پینگ داخل بازی نیست و ممکن است با بعضی محدودیت‌های اینترنت قابل اجرا نباشد.

## ساخت APK با Android Studio
1. Android Studio را نصب کن و این پوشه را با گزینهٔ **Open** باز کن.
2. اجازه بده Gradle Sync و دانلود وابستگی‌های رسمی انجام شود.
3. اگر خواست، JDK سازگار با Android Gradle Plugin 8.7 را انتخاب کن (JDK 17).
4. از منوی **Build → Build APK(s)** استفاده کن. خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` است.
5. قبل از استفادهٔ روزمره، روی گوشی تست کن؛ در صورت بروز خطای Sync یا کامپایل، متن خطا را بفرست.

## قالب JSON نمونه برای واردکردن پروفایل‌ها
```json
[
  {"name":"سرور آزمایشی من","type":"WireGuard","address":"example:51820"},
  {"name":"پروفایل دوم","type":"OpenVPN","address":"فقط یادداشت آدرس"}
]
```
این قالب فقط برای مدیریت یادداشت‌هاست و فرمت کانفیگ واقعی WireGuard/OpenVPN محسوب نمی‌شود.
